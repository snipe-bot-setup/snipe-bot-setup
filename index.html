🔐 Important Permission Guide

Administrator: Gives almost complete server control. Avoid granting it unless genuinely necessary.

Manage Roles: Allows a bot to create, edit and assign roles below its highest role.

Manage Channels: Allows creating, editing and deleting channels.

Manage Server: Allows access to important server settings.

Manage Messages: Allows deleting other members' messages.

Kick Members: Allows removing members from the server.

Ban Members: Allows banning members from the server.

Moderate Members: Allows timing out members.

Mention Everyone: Allows @everyone and @here announcements.

View Channels: Allows the bot to see permitted channels.

Send Messages: Allows the bot to respond.

Embed Links: Allows rich embeds in messages.

⚠️ Security Rules

  • Never give Administrator automatically.
  • Only authorize bots from their official websites.
  • Check the server name before authorizing.
  • Give each bot only the permissions its features need.
  • Keep bot roles above the roles they need to manage, but below owner-level roles.
  • Test bots in a restricted channel first.
  • Review permissions periodically.

📌 Before Adding a Bot

1. Click the bot's official invitation button.

2. Select your Discord server.

3. Review the requested permissions.

4. Remove unnecessary permissions where possible.

5. Authorize and configure the bot.

6. Test that its features work correctly.
